# Asset provenance

The repository contains custom UI icons, onboarding screenshots, exercise
animations, testimonial imagery, and a Lottie animation under `assets/`.

Before publishing, the copyright holder must record the source and applicable
license or ownership basis for each asset group below. Git history alone does not
establish redistribution rights.

| Asset group | Path | Source / license evidence |
| --- | --- | --- |
| UI icons | `assets/icons/` | **Owner confirmation required** |
| Onboarding screenshots | `assets/images/img-phone-sample-*.png` | **Owner confirmation required** |
| Exercise GIFs | `assets/images/img-sample-exercise-*.gif` | **Owner confirmation required** |
| Loading animation | `assets/animations/wave.json` | **Source license required** |

Do not treat this inventory as a license. Remove or replace any item whose rights
cannot be documented before making the repository public.
